A societal interaction simulator set on a collection of remote islands.

Github: https://github.com/J-Sexton0075/WHACK-26

AI Usage: Generative AI was used in the creation of this project by members of the team. 
- I personally didn't use AI *at all* (neither for code generation or for assistance writing code)
- My other three team members used AI in varying quantities both for generating code and assistance.
- AI Usage was agreed upon between the team before we started this project. I was aware that they were planning on using AI and they were aware that I was not going to.
- Throughout the code there are generated documentation comments by various AI models which were included, and there are two .md files in docs/ which were generated by AI. 

My goal going into the Hackathon was to gain some experience building a project, and I think delegating AI to doing that takes away from the experience. I'll probably write more about my thoughts on here some other time but I prefer avoiding it as much as possible (which in most cases ends up being avoiding it completely).
